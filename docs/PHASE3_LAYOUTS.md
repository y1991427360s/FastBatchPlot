## 实现范围

- 搜索范围新增当前空间、仅模型、所有布局、模型和布局；两宿主通过 `LayoutDictionary` 只读遍历，不为采集切换当前布局。
- 候选与图框携带布局名称、标签顺序、文档实例标识和空间 BTR Handle。来源判定使用实例与 Handle，布局改名不依赖旧名称。
- 修复多段线检测前置去重跨空间吞图：同坐标不同布局、不同文档的图框分别保留。面积阈值继续按空间独立计算。
- 排序先按文档出现顺序、布局标签顺序分组，再在每个布局内按所选规则排序，最后统一编号。图号排序也遵循此布局分组规则。
- 表格新增只读布局列。追加逻辑列后调整显示位置，保留原编辑列索引与行对象绑定，避免改错图纸。
- UI 预检通过可选 `ICadLayoutHost` 验证来源布局是否仍存在；旧宿主保持当前空间限制，不会静默把跨布局搜索降级为当前空间。
- 两打印引擎在文档锁内建立布局上下文，结束读事务后切换目标布局，打印事务结束后恢复原布局及视图，恢复成功后才提交 PDF。
- 切换和恢复同时核对布局名称及空间 ID，避免浮动视口与模型共用 Model BTR 时跳过恢复。来源不属于活动文档、布局消失、空间不符、恢复失败均明确失败。
- 块几何采集失败进入快照警告；旧式 Polyline2d 增加非平面、圆弧及拟合曲线排除，避免仅凭顶点误认矩形。
- 搜索/框选异常和取消保留现有列表及人工文件名。

## 仍需验收与限制

本轮没有连接、启动或操作 CAD。SDK 编译、纯逻辑测试和假宿主 UI 检查不能证明真实 CAD 的布局 setter、文档锁、视图恢复和打印驱动运行正确。布局切换中途异常、原布局视图一致性、版面改名/删除以及跨布局 PDF 比例/页尺寸，仍需获得明确授权后在真实宿主验收。

- 只在当前活动文档内跨布局，不自动切换其他 DWG。
- 起始或目标布局处于浮动视口时明确拒绝；仍只支持未扭转二维俯视图。恢复同时检查布局与空间，恢复失败不提交输出。
- 定位继续要求当前空间一致，用户须先切回对应布局；尚未自动跨布局定位。
- 搜索范围尚未持久化；默认仍为当前空间。局部采集失败目前显示警告数量，尚缺可浏览的逐项诊断面板。
- 任意驱动纸张生成、多格式、实际打印机、DWG 拆分、模板区域文字提取及写回、完整目录统计、签章库、真实预览和任务取消仍未完整实现。
