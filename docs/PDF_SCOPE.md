# PDF 专项工作范围

> 2026-09-24 更新：用户要求只做中望 CAD 批打印，暂不适配 AutoCAD。发布包默认只含中望版；AutoCAD 适配层源码保留并继续编译，但不再作为交付和验收目标。阶段 46 的修复与原生验收清单见 [阶段 46](PHASE46_ZWCAD_UPGRADE.md)。

2026-09-20 用户明确调整目标：不需要出图章、注册章等图章功能，只需要打印 PDF 相关功能。此要求覆盖此前“复刻全部功能”的范围。

## 保留的目标

- 模型和布局选图、框选与自动识别、图框模板及打印范围。
- 标准、加长和自定义纸张，精确比例、方向、四边留白、居中及边线。
- 打印设备、CTB/STB 样式选择及缺失预检，PDF 参数能力与真实输出一致。
- 排序、图号及文件命名、冲突检查、单页 PDF、合并 PDF 和书签。
- 实际打印预览、逐页结果、取消、部分失败与重试、性能、设置保存。
- 以核心计算/文件服务和薄 CAD 适配分层，保持 CAD 调用在宿主线程。

## 已退出目标

签名、图章、出图章、注册章、图章库、授权码、有效期、共享及原版商业注册；实体打印、多格式导出、DWG 拆分和独立文档编辑不再追加功能对齐工作。

已有非 PDF 兼容代码暂保留，不以其缺口阻塞 PDF 交付。取消中的双章代码不接入两宿主输出；主界面与模板界面撤下签章入口，预览/打印前清除历史附加资源，避免访问旧库或弹出授权。图纸本身已有的图形按原图图层可打印状态处理，不因为停做签章模块而删除或强制隐藏图元。

## 当前验收边界（2026-09-25）

阶段 45 记录过原生 PDF 输出与来源核验测试；阶段 46 随后调整了来源指纹与输出检查行为，其待验清单继续有效，不能用阶段 45 的旧实现描述代替当前实现。

阶段 47 完成当前测试 DWG 的字段提取与模板库直接拾取：60 张，57 张普通图纸逐项属性对照通过，3 张目录按原配置通过，无字段警告；647 项核心测试、391 项离线 UI 检查通过。原始 TK 和用户模板库保持不变。见 [实机记录](PHASE47_TITLE_EXTRACTION.md)。
