# 阶段 35：无留白最外边线控制

原版帮助第 14 问提供“不留白时，打印最外边线”的开关。本项目此前在两宿主遇到 false 就报不支持，主界面也没有入口。现已接入“四边…”窗口，并提供裁切宽度。

## 实现与准确边界

关闭开关且四边留白均为 0 时，打印窗口按纸面宽度向内裁切四边。默认 0.25mm，可设 0.01—5mm。窗口在 CAD 单位中内缩“宽度 × 实际比例分母”，纸面原点补回相同宽度，所以纸张大小、比例和内部点纸面位置不变。使用已应用的模板打印范围，而不是忽略模板回到原图框。

预览、正式输出、自定义纸张预览和历史重试均调用同一 PlotPlanBuilder。默认保留边线，旧设置缺字段时保持默认。新任务保存裁切宽度，旧历史缺宽度时使用 0.25mm。源图框、图层、实体不因裁边而修改。

这是边缘裁切实现，不是识别并隐藏特定实体。粗边线若超出裁切带仍可能残留，裁切带内的文字或其他图形也会被裁掉；界面明确说明并允许调整。原软件内部算法未公开，本次不能据此宣称不同线宽场景已与原版逐像素一致。任意一边有留白时不裁边，符合该选项“不留白时”的前提。

非有限/越界裁切宽度、内缩后窗口消失或坐标精度不足会在任务预检中失败。裁切宽度进入用户设置、任务冻结副本、历史和详情展示。两宿主已移除旧的无条件拒绝，直接使用计划窗口和原点。
