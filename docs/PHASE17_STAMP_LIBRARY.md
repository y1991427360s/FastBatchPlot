# 阶段 17：透明 PNG 印章库、模板定位与临时输出

日期：2026-09-20。依据原版帮助第 9 页：透明 PNG 入库、共享库、图框模板印章区域、打印时附加。本阶段补齐资产与定位链路，不代表签章功能已完整复刻。

## 已实现

- 主窗口表格右键“印章库与附加印章”可新建或打开 JSON 库、导入透明 PNG、预览、改名、删除和选择。确认前只编辑内存，取消不落盘。无修改确认不重写库，允许只读共享库使用。
- PNG 内嵌库中，可随库移动；不依赖导入时的图片路径。校验完整 PNG 块、CRC、结束标记、解码尺寸和透明/可见像素，拒绝动画、损坏、全透明及全不透明图。单张上限 8 MiB / 1600 万像素，单库最多 64 枚 / 6400 万像素，并限制文件及编码总量。
- 同目录排他锁、内容摘要版本比较、刷新临时文件后原子替换，拒绝覆盖陈旧或损坏库。摘要仅用于并发检测，不构成授权或防篡改凭证；共享存储须提供 Windows 文件锁及原子替换语义，不承诺离线同步副本间的分布式冲突解决。
- 图框模板新增独立印章区域，与打印范围分别存储。以模板本地右下角为基准，按图框变换转换到 WCS，按图片原比例居中，支持核心几何中的旋转和镜像，拒绝剪切、倾斜、外参及越出打印窗口。
- 正式打印/预览前重新读库；任一图纸无匹配区域、资产失效或定位异常时阻止批次。任务冻结图片内容及逐页位置，避免同批混用不同版本；每页执行时再次验证图框位置。默认设置仅保存库路径与 ID，不保存图片副本。
- “印章输出”同时控制映射印章层与本次附加印章；关闭时不读库、不插图。已有选择时显示“已选附加”。没有选择资产时不插入任何图片。
- AutoCAD 2018 / ZWCAD 2026 使用唯一临时 PNG、临时图层、图像定义与 raster；向量表示完整图片边长，设置后读回校验，避免中望静默拒绝 Orientation。图片实体明确可见且不额外施加实体透明度。
- 正式打印与预览共用插图流程。绘制结束或失败后在事务仍有效时卸载图片；临时数据库对象通过 Abort/Dispose 回滚。IMAGEFRAME 和 BACKGROUNDPLOT 恢复、临时 PNG 清理完成后才报告成功；文件输出随后校验并原子提交。实体打印失败会提示可能已进入打印队列，不能盲目重试。

## 尚未完成与验收边界

- **内容授权码、有效期、签名曲线录入/共享/插入尚未实现。** 本阶段库是未加密、无授权限制的自有 PNG 资产库，不能用作受限印章分发系统，也不能声称完成原版签章功能。
- **没有原生验收。** 未提交事务中的 raster 是否进入实际打印图形、无 reactor 临时图片、PNG alpha、镜像、布局/视口图层可见性、图片缓存释放、源图 DBMOD/撤销状态仍需专用测试图验证。SDK 编译与假宿主测试不能代替这些证据。
- IMAGEFRAME 暂时设 0 会令本页所有光栅图片边框均不输出；界面已说明，结束后恢复原值。这不是单张图片的边框控制。
- 当前任务使用启动时内容快照；运行中更改库不会改变本批图片。未来内容授权模块需另行定义逐页有效期、撤销与离线校验策略。
- 尚未覆盖非模板多段线图框附加印章、原版专有库格式导入、原图中已有印章授权检查，以及布局 DWG 拆分等其他剩余功能。
