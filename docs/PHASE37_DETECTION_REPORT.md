# 阶段 37：识别报告

## 问题与改动

搜索快照原有逐实体读取警告，但主窗只展示警告数量；核心识别丢弃的小尺寸、非矩形、自动纸张匹配失败和重复内框缺少可查看的原因。新增“识别报告”，在搜索/框选完成后保留一份只读快照，展示候选数、保留数、过滤原因、来源文件、空间、实体编号、图层及块名。采集警告保留原文，可在报告窗口选择复制。

诊断作为可选参数贯穿块、模板、多段线和最终选择服务，不重新扫描 CAD，不改变默认识别规则。指定块名时提前排除多段线，与原最终筛选结果一致。报告完整累计原因数量，但只保留前 2000 条过滤明细；采集警告同样最多展示 2000 条。修正主窗重复计数遗漏多段线内部去重的问题。

搜索失败和框选取消/失败会替换报告说明，原图纸列表及人工文件名保持不变。报告带时间和当次筛选条件，避免后续编辑列表时误把它当实时诊断。

## 范围

报告只覆盖宿主交给识别器的候选。宿主在采集前未纳入的实体不能从此报告追溯；框选接口目前不提供逐实体采集警告。模板解析异常仍整次失败并保留旧列表，不静默输出不完整结果。图章功能未增加。
