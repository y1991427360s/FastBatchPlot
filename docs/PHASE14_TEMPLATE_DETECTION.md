# 第十四阶段：模板图框搜索接入与实际范围筛选

日期：2026-09-20。修复第十三阶段记录的“原块包围盒不规则导致模板块提前被过滤”缺口。全功能目标仍未完成，本阶段没有启动、连接或操作CAD。

## 实现

- 新增核心 TemplateFrameDetector，已登记且有打印范围的模板块不再先走通用100单位最小尺寸和8%纸张相似度过滤。先根据模板解析实际范围，再确定出图比例和纸张。
- 模板新增可选 PrintScale（0自动，正数为指定比例分母，最多1000000），裁切窗口可设置小数比例。旧模板字段缺失默认0。
- 自动比例优先尝试等比插入缩放提示，不能匹配时重新推断；仍不可靠则明确报错，提示填写模板比例。不把未知比例伪装为默认A1。
- 指定比例支持任意矩形纸张，按实际范围/比例算毫米尺寸，精确接近标准图幅时命名为标准纸，其余为自定义。纸张是否可输出仍由驱动精确介质匹配决定。
- 搜索和框选统一经过模板解析。图层/指定块条件在解析前过滤，避免无关对象错误阻止当前搜索；命中模板解析失败则中止并保留旧列表，不返回漏图的部分清单。
- 模板自动应用打印范围、身份和排序优先级。模板无裁切时继续通用几何识别，但无需先提取文字也可获得模板排序优先级。
- 去重与面积阈值按 PrintBounds（无裁切时原范围）比较。模板裁切框优先保留，避免被附近通用多段线框替代而丢失模板字段信息。

## 限制与后续

- 本轮是假宿主与纯核心验证，未证明真实动态块/布局/镜像/图框采集结果。原生范围转换与打印仍待验收。
- 自动推断仍采用既有标准比例/纸张算法；遇到特殊工程比例须明确填写模板比例。模板设置中的比例用于新搜索；右键重新应用裁切仍保留列表当前比例，避免覆盖人工修改。
- 搜索自动应用范围，但尚不自动提取全部标题字段，需要点击“提取图框信息”。
- 模板裁切仍不支持外参、倾斜平面和任意角度旋转；无裁切的模板块仍遵守通用几何过滤。
- 已注册模板的实际范围解析逐块调用宿主，每块独立只读锁/事务；大规模图框可继续优化为批量解析接口，需确保异常定位与文档一致性。
- 既有未完成项继续：任意纸张生成、光栅DPI/背景、共享块文字写回/自动居中、签章、布局和依赖完整DWG拆分、真实预览、任务恢复、Excel目录版式模板、两宿主原生全流程验收。打印原点/旋转与宿主消息循环待验收项保留。
