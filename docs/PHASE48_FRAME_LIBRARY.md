# 阶段 48：图框信息库管理改版（2026-09-26）

用户反馈原“图框模板库”窗口难用，要求仿照 `M-批打印软件(中望版)V20260805B` 的“图框信息库管理”，只保留录入新图框、导出设置、导入设置、确定、取消。签章仍不在范围内。

## 界面

- 图框信息库管理（`UI/Views/TitleTemplateForm.cs`）：列为序号、图框对应的图块、对应纸张、排序优先级别、删除、文件命名规则、图号(A)、版次(B)、图名(C)、日期(D)、信息1(E)、信息2(F)。√ 表示已录入该信息框。双击空白处录入新图框，双击记录修改，点“删除”确认后移除，Delete 键同样可删。修改在“确定”时才保存；取消或窗口 X 在有修改时先确认。
- 录入新图框（`UI/Views/FrameEntryForm.cs`）：1、基本信息（选择对应纸张、定义文件命名规则、排序优先级别，默认 2）；2、信息框录入（六个点取范围按钮、调整图框打印范围，勾选框表示已录入并可点击清除）；从已录图框复制信息、确定、取消。原版的印章框段按范围要求不提供。
- 文件命名规则设置（`NamingRuleForm`）用原版字母 ABCDEFT，连写两次表示字母本身，实时显示示例：`A(B版)(T)_C_RFF` → `建施03(A版)(A1)_一层建筑平面图_RF`。留空表示使用主界面通用命名；含花括号时按占位符模板原样保存。
- 选择对应纸张（`PaperChoiceForm`）：标准及加长图幅、竖向切换、自定义宽高。

旧窗口的名称/块名文本框、属性标签列、手工坐标列、复制模板、专用目录编辑按钮已撤下。已有模板中的属性标签规则、专用目录、印章区域等数据在修改时原样保留。

## 数据规则

纯逻辑集中在 `Core/Templates/FrameLibrary.cs`：

- 字母与字段：A 图号、B 版次、C 图名、D 日期、E 信息1（ProjectName）、F 信息2（SubProject），与 `.tk` 信息框和命名占位符一致。
- 录入新图框：在 CAD 选择图框块后，优先按图框线框的本地尺寸推断纸张（方向与图框一致），读不到时按块的世界范围推断；不能可靠识别时提示用户选择。模板名称默认取块名，同块其他尺寸追加纸张名。
- 同一图块、同一纸张（不分方向）已录入时打开原记录修改；无纸张的同块旧记录也视为同一图框，并补上识别的纸张。
- 点取的区域取代该字段原有规则（含属性标签），坐标仍为模板本地右下角基准。
- 导入合并：同一图块同一纸张的记录由导入内容替换并沿用原名称和标识；其余追加，名称或标识冲突时重新分配。选择“否”时只保留导入内容。导入不存在的文件会报错，不会导入空库。

## CAD 接口

新增可选接口 `CadBridge/ICadTemplateFrameHost`，中望实现 `ZwCadAdapter.TryGetTemplateFrameRegion`：按与 `TemplateAnchor` 相同的筛选（可见、非冻结/关闭图层、非文字/属性定义/构造线）求块定义线框范围，换算为右下角基准区域，登记为新图框的打印范围。这样新图框与导入 `.tk` 的图框走同一条识别路径（登记纸张推算比例），导出 `.tk` 的块范围也采用块内单位。`TemplateAnchor` 本身未改动。宿主不支持或读取失败时不登记打印范围，出图按整个图块识别。AutoCAD 适配层未实现该接口。

CAD 点选期间隐藏录入窗口、图框信息库和主窗口，结束后按层次恢复（`FrameLibraryStyle.HiddenWhile`）。
