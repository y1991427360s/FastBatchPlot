# 第十三阶段：模板打印范围与裁切计划

日期：2026-09-20。对照原版帮助第7页“调整图框的打印范围”。完整复刻目标仍未完成；本阶段没有启动、连接或操作CAD。

## 实现

- 图框模板新增可选 PrintRegion，采用与字段区域一致的本地右下角基准。支持数值编辑、样本块拾取、关闭裁切、模板复制/导入/导出；旧模板无该字段仍兼容。
- 新增 `ICadTemplateCropHost`，两宿主通过来源文档、BTR与块句柄定位图框，使用动态块已求值定义的非文字几何基准，再将四角经完整 BlockTransform 转为WCS。
- 核心 `TemplateCropGeometry` 检查四角：支持轴对齐、缩放、镜像和90°倍数旋转；拒绝斜矩形、退化范围、无效坐标，避免把斜框包围盒当成精确裁切。
- 列表右键“应用模板打印范围（勾选图纸）”整批解析成功后才更新。任一页缺少范围或解析失败时，全部列表保持不变。另有“恢复原图框打印范围”。
- 原框 Min/Max、Handle和来源身份不变，另存 PrintBounds 与 AppliedPrintRegion。保持用户出图比例，根据裁切范围重新计算真实纸张，匹配已知标准纸或标为自定义。恢复原范围同样按原范围与当前比例重算纸张。
- 打印计划使用 PrintBounds，其他来源定位、DWG拆分和标题写回不被改为裁切框。批量任务快照深复制应用区域，避免编辑模板污染执行中的计划。
- 两宿主打印每页前重新解析应用区域，若图框变换/动态几何导致范围变化则停止该页，提示重新应用范围。几何变化不被静默忽略。

## 未完成范围和验收边界

1. 未实际打印；块变换、右下角基准、动态块求值、镜像以及SDK打印窗口行为尚须两宿主原生验收。纯核心四角测试不证明CAD宿主实际裁切结果。
2. 目前只接受WCS轴对齐打印矩形；任意角度图框须后续实现可旋转打印坐标系。外参和倾斜图框暂不支持。
3. 模板裁切需要先搜索到块。当前识别器会按原块包围盒与纸张相似度过滤，因此包含额外图形而比例偏差过大的模板块可能在进入列表前被过滤；后续须让已注册模板块绕过通用纸张比例过滤并使用模板范围识别。
4. 裁切范围需要在右键菜单显式应用；修改模板不会自动改变已应用的列表范围，须再次应用。搜索结果重新生成后也需重新应用。无裁切内容可视预览和自动居中文字功能。
5. 恢复原范围不会恢复此前手工指定的纸张，而是保持当前比例重算尺寸；界面明确提示检查图幅。裁切可以指定超出原包围盒的矩形，以便支持代表性定位块。
6. DWG拆分仍按原图框范围，不随打印裁切改变；实体不被实际裁剪或删除。
7. 仍待任意纸张、光栅DPI/背景、共享块写回、标题自动居中、签章、布局及依赖DWG拆分、真实预览、任务恢复、Excel目录版式模板和两宿主全流程验收。打印原点/旋转与消息循环既有疑点继续保留。
