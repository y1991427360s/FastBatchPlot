# 第十一阶段：逐页任务状态机、取消与完整合并

日期：2026-09-20。全功能目标继续；本阶段无 CAD 启动、连接或操作。

## 已实现

- 新增核心 `BatchPlotRun` / `BatchPage`：Pending、Running、Succeeded、Failed、Cancelled、NotSubmitted 状态，页面和打印配置深复制快照，输出路径只读。调用者拿到的 Frame/Config 再复制，避免外部修改正在运行的数据。
- 主界面按当前表格显示顺序规划批次。WinForms Timer 在窗口线程每次提交一页，页间交还消息循环；无后台 CAD 调用，无产品侧 DoEvents。重入 tick 和重复任务启动被阻止。
- 新增“取消批量任务”按钮。取消在当前页完成后生效，未提交页标记取消，已完成文件保留；不尝试回滚已接收的实体打印机任务。
- 每页重新核对宿主实例和来源文档/空间，文档变更时该页不提交；设备失败停止所有后续页，文件输出失败记录后继续其余页。
- 仅全部页面成功且未取消才允许合并。取消或失败批次保留单页、不给出完整合并文件。最后一页之后仍留一次消息循环供取消合并。
- PDF 合并增加不覆盖提交选项；批量输出使用 File.Move 提交，消除“先检查不存在、合并期间目标出现、最后覆盖”的竞争窗口。独立 CLI/旋转原有覆盖语义保持。
- 任务期间界面编辑和关闭继续受阻；完成/取消后恢复控制状态。

2. 本轮只覆盖打印/格式导出，DWG拆分与标题写回仍有各自同步流程，取消按钮在这些任务中禁用。
