# 第六阶段：Excel 目录与面积折算

日期：2026-09-20。全功能复刻尚未完成，本文记录本阶段源码与离线证据。

后续列表编辑与最新构建包见 [第七阶段记录](PHASE7_LIST_EDITING.md)，本文包路径与验证为第六阶段历史记录。

## 已实现

- 导出入口支持真正的 `.xlsx` 及带 UTF-8 BOM 的 CSV。XLSX 使用 C# OOXML 写入，无 Excel COM、Office 安装或 Node 运行时依赖，支持当前两个插件目标框架。
- 目录设置提供 17 种字段、列勾选、上移/下移、列名、列宽、行高、标题，默认仅勾选图纸，可导出全部列表。默认列为序号、图号、图名、图幅、比例、版次、日期、布局。
- 目录保留当前列表顺序，图号/名称等以显式文本单元格写入，序号及统计为数值。可识别的完整日期写为日期数值，其他日期原文保留。小数比例不取整。
- “纸张统计”按图幅名称及实际长短边分组，横竖方向相同尺寸归一，同名不同尺寸分开。面积及 A1 折算使用公式并保存缓存值；A1 基准为 841×594mm，即 0.499554m²。折算不计打印份数、留白或耗损，表内明确说明。
- XLSX 包含冻结表头、筛选、打印重复表头、A3 横向及按一页宽度分页。宽表可能被打印缩小，尚无智能拆列分页。
- 导出先校验后写同目录临时文件，再原子替换；没有明确允许覆盖时拒绝已有目标。异常保留旧文件。空清单、无效尺寸、重复字段、非法 XML 字符和过长单元格明确失败，不截断或低估统计。
- CSV 新入口使用相同字段设置；来自图纸的公式前缀文本转义，图幅名也正确处理引号与逗号。旧 CSV 接口同时修复重复枚举和图幅名称未转义问题。

## 剩余边界

目录设置尚未持久化或绑定图框模板；暂无用户现成 Excel 模板导入、目录写入 CAD、按指定计费规则取整、动态行高测量。统计是导出时分组的当前图纸快照，用户后来在目录表修改图幅不会重建统计分组；统计表自身尺寸/张数编辑会通过公式重新计算。

本阶段补齐可配置 Excel 目录及 A1 面积折算基础，不能等同于原版全部定制目录能力。任意纸张、DWG拆分、模板字段写回、签章、真实预览与取消等继续保留在全目标清单。
