# 阶段 36：搜索前指定识别比例

## 缺口

原版帮助第 2—3 页说明，打印范围尺寸除以指定比例得到纸张尺寸。此前核心识别器存在 preferredScale 参数，但主窗口搜索/框选从未传入，且非标准长宽比仍被过滤。用户只能在已识别列表改比例，无法找回先被过滤的非标图框。

## 修改

顶部增加“识别比例 1:（0自动）”，支持小数并保存默认设置。0 保持既有自动标准纸张推断与过滤；显式正数则按范围尺寸除以该值生成纸张，标准名仅作尺寸接近时的标签，不把实际尺寸吸附到标准值。例：50000×10000，1:100 → 500×100mm。

块、多段线、模板识别在搜索和框选中均消费该参数。模板明确的 PrintScale 优先，模板自动比例则使用主窗值，再回退自动推断。模板未设置打印范围时也保留明确比例。块插入缩放只在自动模式作为提示，不覆盖用户显式比例。

保留矩形、最小图框尺寸、块名/图层、重复/内框及面积过滤。指定比例放宽的是标准纸张长宽比判断，所以可能同时识别满足几何条件的设备框；可配合指定块/层筛选。比例改变只影响后续搜索/框选，不暗中重写现有列表。每页的最终比例和纸张已进入原有任务历史。
