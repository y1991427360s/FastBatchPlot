## 结论

当前项目是一个已经有分层骨架的批量 PDF 打印原型，尚不能认定为原版的完整替代品。主要差距不在界面风格，而在出图正确性、完整业务流程和可靠交付。现有说明中的“完整复刻”“全功能”“跨版本完全通用”“精准 ACI”“流式多级书签”等表述没有相应实现或验证支撑。

值得保留：C# 核心算法与宿主桥接分层、AutoCAD/ZWCAD 双适配的方向、PDF 合并与一级书签、自然排序、UTF-8 BOM 的中文 CSV 输出、已有 31 项测试。不建议推倒所有代码；应先修复错误，再沿现有边界拆出应用服务和任务规划。

本轮检查未修改产品源码、未安装插件、未启动/连接/操作 CAD。新增审查文档、可重跑复现脚本与测试证据；构建会生成 `bin/Release`，但没有替换已安装插件或旧部署包。用户的“全部功能且更好”是后续交付目标，目前未达成。

## 建议采用的现代化架构

优先保留 C# 和薄 CAD 插件。现代化的重点是可测试、明确状态、可恢复以及正确隔离 CAD 线程，而非立即更换 Web 界面或引入微服务。

```text
UI（绑定稳定页ID；只展示/编辑草稿）
  ↓
Application（识别、模板、预检、生成计划、任务控制、汇总结果）
  ↓                      ↓
Domain（不可变值对象）    Ports（CAD调度、设备、文件、配置、签章、时钟）
  ↑                      ↑
Core algorithms          CAD adapters / PDF services / Storage
                         ↑
              分宿主与版本的组合入口、发布包
```

建议逐步增加 `FastBatchPlot.Application`、`FastBatchPlot.Pdf`、`FastBatchPlot.Infrastructure`，无需一次拆出大量空项目。Core 暂保持 netstandard2.0 支持旧宿主；新版独立工具使用当时受支持的现代 .NET，宿主插件目标框架严格跟随 CAD 官方要求。AutoCAD 2025+ 的 net8 插件需独立目标和 SDK 依赖，不应把 net48 DLL 声明成通用。

- `DrawingContext`：源文档会话、布局、图形单位、视图/坐标变换、数据库版本；不能只存活动文档。
- `FrameCandidate`：稳定 ID、实体 Handle、源上下文、原始几何、拒绝原因及识别置信度。
- `PaperSpec / Scale / Margins`：不可变物理值对象，单位明确；自动推断遇到多个等价解时显示候选，不能擅自宣称唯一正确。
- `PlotPlan`：执行前冻结来源、窗口、介质实际尺寸、旋转、精确比例、CTB/STB、格式、份数、目标路径；设备能力预检后才能执行。
- `PlotJob`：Draft → Validated → Running → Succeeded / PartiallyFailed / Cancelled / Failed；每页独立结果和错误。忙碌、旧文件、缺页均不得归为成功。
- `ICadDispatcher`：CAD API 只在允许的宿主线程/命令上下文串行执行。PDF 合并、哈希、文件处理可在后台，禁止直接 Task.Run 包住 CAD API。
- `OutputPlanner`：提前校验冲突、保留手工名称、路径约束、临时目录隔离；文件验证后原子提交。取消/失败保留明确可恢复成果，禁止拿旧 PDF 冒充新结果。
- `TemplateRepository / SettingsRepository`：带 schemaVersion 的 JSON，原子写入、备份和迁移；模板保存字段区域、裁切范围、排序优先级、签章区域及导出格式。
- 签名/印章作为独立内容资产和授权模块；保留用户提供资产、共享库和有效期语义，不复制原版收费/设备绑定机制。
- 统一打印规划、介质匹配和候选收集；AutoCAD/ZWCAD 适配器仅负责类型/API差异，避免两份业务逻辑持续分叉。

性能先测再改：当前全图扫描两次且每次都提取两类对象，应一次快照后处理；缓存 Bounds 和聚类统计，之后再评估空间索引。PDF 不声称无限大文件可用，要用 100/1000 页样本记录内存、耗时、失败后残留。

## 最终验收矩阵

纯自动验证可先做：几何误判/漏框、纸张引用隔离、合法文件名/重名、源上下文校验、比例和留白计算、任务异常/取消、PDF页数/尺寸/书签、截断任务、配置往返、中文CSV。UI 用假宿主测试排序编辑一致性及不同DPI布局。

取得用户明确 CAD 验证授权后，使用专用测试图执行，不能直接把正式工作图当测试图：

- A0—A4 横竖、加长和非标纸；同图混块/多段线；缩放1的模型尺寸块与纸张尺寸缩放块。
- 1:1、1:2.5、1:50、1:100；用已知长度量 PDF；正负与不等边留白。
- 模型、多布局、跨文档切换；旋转UCS/视图、OCS、外参、动态图框、镜像、缺字体。
- 无设备/纸张/样式、不匹配 CTB/STB、打印引擎忙碌；缺权限、磁盘不足、已有同名文件、损坏PDF。
- 中途取消、关闭窗口、页面部分失败、失败重试；汇总与实际文件完全一致。
- 签章到期/无授权、共享库离线、透明图与边框、DWG拆分标注依赖。
- 100/150/200% DPI、默认与最小窗口；安装/升级/卸载，每个声称支持版本分别验收。

原版功能对齐必须最终有逐项结果和交付证据。当前报告完成了审查基线与可执行路线，没有把待开发、待原生验证项目标为已完成。
