# FastBatchPlot 中望 CAD 批打印使用说明

适用：**中望 CAD 2026（64 位）**。当前交付目标只有中望版；AutoCAD 源码保留但不在默认发布包中。

## 1. 安装与加载

1. 用 `deploy\Build-Release.ps1` 生成的发布目录（`artifacts\FastBatchPlot-日期时间\`）进行安装，不要使用源码 `deploy` 目录。
2. 保存图纸并**关闭中望 CAD**，双击发布目录中的 `一键安装.bat`。安装到 `%LOCALAPPDATA%\FastBatchPlot\ZWCAD2026`，只写当前用户的中望自动加载注册项。
3. 重新打开中望 CAD，命令行出现“FastBatchPlot … 加载成功”即可使用。卸载用 `一键卸载.bat`，用户设置保留。

临时试用也可以在中望 CAD 中 `NETLOAD` 发布包内的 `ZWCAD2026\Contents\FastBatchPlot.ZWCAD.dll`（已加载的 DLL 无法在同一 CAD 会话中替换，更新版本需重启 CAD）。

## 2. 命令

| 命令 | 功能 |
| :--- | :--- |
| `BP` / `BATCHPLOT` | 打开批打印主窗口（再次输入只激活已打开的窗口） |
| `BP_TY` / `BPTY` | 以“通用型”模式打开：识别矩形多段线与图块 |
| `BP_TK` / `BPTK` | 以“图框型”模式打开：只识别已导入模板的图框块 |
| `BP_TRUE2INDEX` | 把实体、图层及块定义中的真彩色转为 ACI 索引色（锁定图层跳过并提示），解决黑白样式打印仍有彩色的问题 |
| `BP_INSERT_TK` | 在指定点插入 A0～A4、A3+1（A3L）、A2+1（A2L）矩形图框 |

## 3. 批量输出 PDF

1. **识别图框**：选择模式与搜索范围（当前空间 / 仅模型 / 所有布局 / 模型和布局），点“搜索图框”；或“从图中框选”“两点添加图纸”“选择图集添加”。可按图块、图层、面积、识别比例筛选，重复框和内含框默认过滤。“识别报告”列出每个被排除候选的原因。
2. **核对列表**：图幅、比例、基础尺寸、文件名均可直接编辑；点击“出图比例”“基础尺寸”表头可统一修改全部图纸；右键菜单提供纸张统计（含折合 A1）、批量改图幅/比例、图号重编、上下移动、打开输出文件等。
3. **输出设置**：选择打印设备（默认优先 `M_PDF.pc5`，其次中望原生 `DWG to PDF.pc5`）、打印样式、输出目录、命名模板；勾选“合并为单份PDF(带书签)”可生成带书签的合集。
   - **覆盖同名文件**（默认勾选）：重新出图时替换同名成果；新文件先写到临时文件并校验页数、纸张尺寸，成功后才替换。同名文件被 PDF 阅读器占用时，会在出图前提示关闭。
   - **完成后打开**：批次结束后在资源管理器中定位合并 PDF 或打开输出目录。
4. 点“开始批量输出”。标题栏显示进度（如 12/80），可随时“取消批量任务”（当前页完成后停止，已完成的单页保留）。

非标准尺寸（例如会签栏伸出外框、加长图幅或指定比例后的非标纸张）会自动生成私有临时纸张配置，**不修改** CAD 或其他插件（如 `M_PDF`）的 PC5/PMP 文件；若驱动只接受打印机目录中的配置，临时副本也会在打印后删除。

## 4. 图框型（导入原版图框信息配置文件）

在“图框模板”（图框信息库管理）中点“导入设置”，选择原版 `图框信息配置文件.tk`：块名、ABCDEFT 文件命名规则（A 图号、B 版次、C 图名、D 日期、E 信息1、F 信息2、T 图幅，连写两个字母表示字母本身）、纸张尺寸、信息框位置、排序优先级都会读取；录入时的插入比例与旋转会自动换算。导出 `.tk` 时按原版格式（GBK、CRLF）写回。

> 旧版本导入的模板库曾把“命名规则”误当作块名（大量模板块名为 `A-C`），图框型会找不到任何图框。主窗口检测到这种情况会提示，请在“图框模板”中点“导入设置”重新导入原 `.tk` 并选择“否”（完全替换）。

### 图框信息库管理（录入新图框）

点“图框模板”打开“图框信息库管理”，仿原版一行一个图框：序号、图框对应的图块、对应纸张、排序优先级别、删除、文件命名规则及图号(A)～信息2(F)（√ 表示已录入该信息框）。底部只有五个按钮：

- **录入新图框**（或双击列表空白处）：在 CAD 中点选图框块，程序按图框线框自动识别对应纸张（如 A2），并把图框自身登记为打印范围，再打开“录入新图框”窗口：
  - 基本信息：选择对应纸张（标准/加长/自定义，可切换竖向）、定义文件命名规则（ABCDEFT，带输出文件名示例；未定义时用主界面通用命名）、排序优先级别（默认 2，小的在前）。
  - 信息框录入：点取图号(A)/版次(B)/图名(C)/日期(D)/信息1(E)/信息2(F)范围，在 CAD 中框选该信息所在的格子；右侧勾选框表示已录入，点击勾选框可清除。“调整图框打印范围”可裁掉不需打印的部分。
  - 从已录图框复制信息：复制已录图框的命名规则和信息框（以右下角为基准）。
  - 再次选择同一图块同一纸张的图框时，直接打开原记录修改，不会重复录入；动态块的不同尺寸分别登记。
- **双击已有行**：修改该图框。需要点取时程序按块名在当前空间自动找同名图框，找不到会提示在图中点选。点“删除”列可移除记录（需确认）。
- **导出设置**：导出为 `.tk`（原版格式，GBK、CRLF）或 JSON，供其他电脑导入。
- **导入设置**：读取 `.tk` 或 JSON；已有图框时可选“是”合并（同一图块同一纸张的记录由导入内容替换）或“否”完全替换。
- **确定** 才保存到模板库；**取消** 或窗口 X 放弃本次全部修改（有修改时会确认）。打印列表可以为空，不必先搜索图框。

“提取图框信息”只更新列表，不写回 DWG。独立属性块中的字段会一起读取。区域没有文字中心命中时可读取唯一相交文字，歧义则保留原值并报告。应核对实际字段，不只看处理成功数。

## 5. 单张 PDF、历史与日志

- “单张 PDF…”：选中行、两点范围或图形集合快速输出一张，默认输出到临时目录并打开，可另存。
- “更多 ▾”→“PDF 任务历史”：查看最近任务，失败页可重试、完整批次可重新合并。
- “更多 ▾”→“打开错误日志目录”：打印失败的详细信息记录在 `%LOCALAPPDATA%\FastBatchPlot\logs\plot-errors.log`（自动限制大小）。

## 6. 常见问题

- **PDF 颜色淡**：纸张越大线宽相对越细；检查纸张/比例是否识别正确。
- **图形缺失**：图形在不打印图层（如 Defpoints）或打印样式把颜色设成白色。
- **黑白样式仍是彩色**：图形使用了真彩色，执行 `BP_TRUE2INDEX`。
- **布局中的图框**：布局保存时激活了视口也可以直接打印，程序会临时切回图纸空间并在结束后恢复。
- **提示同名文件被占用**：关闭正在查看该 PDF 的阅读器后重试，或取消“覆盖同名文件”改用新目录。
