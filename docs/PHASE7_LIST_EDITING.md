# 第七阶段：图号重编、手动顺序与重复检错

日期：2026-09-20。完整复刻目标仍未完成，本阶段不调用 CAD。

## 功能与入口

- 列表右键新增“重编选中行图号（预览）”“重编全部图号（预览）”“撤销最近一次图号重编”“上移选中行”“下移选中行”。
- 重编按当前表格显示顺序建立计划，支持前缀、后缀、起号、正整数步长、1—9位补零。预览展示图名、旧图号、新图号及布局；不会改动图纸对象。
- 新图号与未重编图纸重复时标红并禁用应用。应用前再次检查对象仍在列表中、旧图号未变化；整批检查通过才修改，不部分应用过期计划。
- 撤销只限最近一次重编，逐对象检查当前图号仍等于该次新图号；若用户已改号、重新搜索或移除对象，明确拒绝，防止覆盖新编辑。没有跨会话撤销历史。
- 手动移动支持多行，保留所选行相对顺序；先采用当前显示顺序，再移动。自动切换“手动顺序”，核心排序在此模式不再按布局分组，允许明确跨布局交错排序。其他排序模式继续遵守布局标签顺序。
- 重编后刷新自动文件名，人工文件名保持；表头排序不破坏对象绑定。
- 重复图号与输出文件名单元格显示红色及悬停原因，单元格编辑、刷新、命名模板改变后更新，冲突解除后清除旧标记。检错覆盖全列表；实际文件输出仍按勾选页执行已有路径/重名预检。
- 命名解析改为单次扫描模板，防止图名/图号内的 `{Date}` 等字面文字被再次解释；异常大序号格式不再分配超长字符串或触发格式化崩溃，未知占位符保留字面文本并清理文件名非法字符。

## 剩余边界

重编修改列表中的标题信息和自动命名，不写回 DWG 实体。原版的图号实体重编号、版次/日期批量写回仍未实现。手动移动当前提供上下移动，尚无拖拽调序；重编/移动没有独立快捷键。重复图号为警示，不自动禁止同号不同名文件输出。文件名检错未扫描输出目录的既有文件，既有文件在任务开始时由输出计划阻止覆盖。

整体待办继续包含任意纸张自动生成、DWG拆分、模板字段写回与裁切、签章、真实预览、取消恢复、目录模板持久化以及全部宿主原生验收。本文通过项目不可代替全功能目标的验收。
