# 阶段 44：重复框与内含框过滤开关

原版 PDF 通用识别提供过滤设置。项目此前只有面积阈值可调，重复框及内含框始终被删除；多段线还在统一候选合并前被提前过滤，导致仅修改最终筛选器无法恢复候选。

主窗新增“过滤重复框”“过滤内含框”独立开关，默认开启，下次搜索/框选生效，可保存为默认设置。关闭过滤不取消用户已选的图层、块名和面积条件。未直接改变当前列表。

联合识别先保留有效多段线候选，再与块候选统一筛选。重复与内含互斥分类，避免关闭重复过滤后相同框又被内含条件删除。原多段线检测公共入口保留默认过滤语义。旧设置文件缺少新字段时仍默认开启，两开关关闭后能完整保存及恢复。

验证：594 项核心测试、388 项离线 UI 检查及 net48 检查通过。新增测试覆盖开关四种组合、块/多段线重复、旧配置迁移、界面识别链路及保存恢复。最小窗口渲染已检查，新开关可见。首次界面用例没有提供重叠候选，修正用例后通过，未降低断言。

发布包：`artifacts/FastBatchPlot-20260920-220229-527`。两宿主 Release 构建成功，8 个项目 DLL 时间、大小和 SHA-256 核验见 `audit-evidence/phase44-artifact-verification.json`。两套包在独立 net48 进程实例化主窗并执行过滤入口，结果均为 `PACKAGE_NET48_FILTER_OPTIONS_OK`。

本轮未连接或操作 CAD。阶段 43 的原生输出异常和跨布局修订事件噪声仍未解决。本轮静态核对 SDK 仅确认 PlotInfo 的验证对象使用借用包装、EndPage 支持 null；未得到原生异常的调用栈，不据此改写引擎生命周期。
