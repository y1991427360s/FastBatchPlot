# 阶段 20：PDF 范围收敛与可靠性修复

2026-09-20 用户明确不需要任何图章功能，只需要打印 PDF 相关功能。双章开发停止，后续以 PDF_SCOPE.md 为准。

## 变更

- 主窗口移除签章开关、映射和图章库入口，模板窗口移除章区域按钮。
- 预览、打印和设置保存前清除历史附加印章选择、资产及授权凭据；图框只做独立快照并清除附加定位，不访问图章库或要求签章宿主接口。原图既有图层遵循自身打印设置，不强制隐藏。
- 已存在的底层签章和多格式兼容代码暂保留；未把取消中的双章流程接入两宿主输出。历史阶段的签章待办退出目标。
- 缺失打印样式时，界面预检和两宿主输出入口均明确拒绝，避免空字符串导致静默继承布局旧样式。用户必须重新选择有效 CTB/STB。
- PDF 合并移到后台文件任务；CAD 逐页调用仍在宿主 UI 线程。合并期间保留编辑锁和取消入口，显示节流后的页进度，结束后统一收尾。
- 合并在页间和临时文件保存后、提交前检查取消。输入单页始终保留，现有目标不覆盖；提交竞争以实际结果为准，过晚取消不否认已经生成的成果。
- PDF 验收拒绝非默认页面 UserUnit，检查有效 MediaBox/CropBox/Rotate（可继承字段沿页面树读取）；拒绝裁切纸张范围、无效矩形或非 90 度旋转。CropBox 只容忍 0.01 mm 坐标舍入。
