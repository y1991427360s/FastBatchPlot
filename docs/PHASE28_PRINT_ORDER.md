# 阶段 28：打印顺序正确性与排序性能

## 问题及修改

自然排序对数字段使用 Int64 解析；超出范围后退回文本比较。例如 `电施-100000000000000000000` 会排在 `电施-99999999999999999999` 前面。新增回归测试在旧实现复现失败。现在按去除前导零后的数字长度及逐字符值比较，不受整数范围限制；保留相等图号的稳定顺序、后缀比较和不区分大小写行为。数字段扫描不再在每次比较时新建正则表达式和匹配集合。

几何排序原先每添加一张图框，都对已有组重复求最小值、最大值及多个平均数。同一行/列有大量图纸时，这会反复扫描同组。现在每组维护边界和累积统计，按原顺序选择首个满足条件的组。35% 重叠、20% 底线阈值、混排图幅、稳定排序、文档和布局分组规则均保留。多个完全分离组之间仍需线性搜索候选组，不声称所有排列均为线性复杂度。
