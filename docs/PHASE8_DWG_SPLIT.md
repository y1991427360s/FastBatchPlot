# 第八阶段：模型空间 DWG 拆分

日期：2026-09-20。全功能复刻目标仍未完成；本阶段只通过源码、两套 SDK 编译、纯核心及离线界面验证，没有生成或打开真实 CAD 图纸。

## 已实现

- 列表右键“拆分勾选图纸为 DWG（预检）”，按当前显示顺序输出；一次性检查文件名、批内重名和既有目标，不覆盖源文件或既有结果。
- 新增独立 `ICadDwgSplitHost`，核心 `DwgSplitPlan` 保存来源和清单副本，避免列表编辑改写已审阅范围。
- 模型空间直接遍历数据库，根据 WCS 二维包围盒相交选取，包含相切和跨边界对象，不依赖当前屏幕、缩放或俯视选择。对象整件保留，不裁切、不爆炸、不平移。关闭图层与隐藏对象也保留。
- 验证来源文档实例、模型空间 BTR、图框句柄和原边界；源框删除、移动、缩放或文档不符时拒绝导出。手选窗口按固定坐标范围处理。
- 预检显示目标路径、实体数、跨界数、警告及阻止原因。无法取得范围的实体会阻止整张图，而不是静默忽略。
- 当前拒绝布局、外参块、图片、PDF/DGN/DWF 底图、代理、OLE及点云对象；嵌套块检查有深度限制。明确避免缺依赖的结果被报告为成功。
- AutoCAD/ZWCAD 适配器使用 `Database.Wblock(ids, Point3d.Origin)` 深克隆关联块/图层/样式，复制 Insunits，保存为 DWG 2013。源数据库使用只读事务；没有调用原生命令或修改源图实体。
- 写入同目录唯一临时 DWG，重新打开临时数据库并检查模型空间顶层实体数，成功后以不覆盖方式移至目标。失败清理临时文件。正式输出前重新检查成员、跨界数量及依赖警告。
- 中途失败停止后续页，已完成文件保留；列表区分成功、失败和未执行，并保留错误原因。

## 必须保留的限制

1. 没有 CAD 原生验收；Wblock 的标注、动态块、关联尺寸、字段及第三方自定义对象需要实际图纸测试。顶层数量核对不能证明图像内容和全部依赖完整。
2. 布局视口拆分未实现。不能把纸空间视口直接放进模型空间后声称图纸完整；需要后续独立方案保留模型和视口关系。
3. 外部依赖当前阻止导出，没有实现文件搜集、路径改写和可搬移依赖包。字体未打包，文字显示仍依赖目标电脑字体。
4. 包围盒相交可能带入范围外内容，旋转图框亦采用轴对齐范围。源框边界不匹配时要求重新搜索；未提供容纳包围盒偏差的猜测降级。
5. 审阅前后比较成员、来源、范围及警告，不是完整实体内容版本快照；同一成员在范围内的修改会按执行时内容输出。
6. 同步批量执行，尚无取消、恢复和完整任务日志。未承诺关联字段跨图后仍保持语义。
