# M-批打印软件深度逆向与完整复刻分析报告

## 1. 原插件逆向分析 (`M-批打印软件(中望版)V20260805B`)

### 1.1 文件构成与职责逆向
通过对原始安装包目录及 PE 二进制元数据的逆向反编译，原插件的核心组件组成如下：

| 文件名 | 类型与架构 | 核心职责与逆向发现 |
| :--- | :--- | :--- |
| `MS_BatchPlot2021.zrx` / `2025.zrx` | 原生 C++ (ZRX 动态链接库) | 包含 Win32 MFC 界面 (`Dlg_BPlot1`, `Dlg_BPlot2`)、图框遍历算法、调用中望 C++ `ZcPlPlotFactory` 打印引擎，以及收费注册与时限检查逻辑。 |
| `ZCAD2021P.dll` | .NET Framework 4.7 托管程序集 | 实现了 `M_PDF_Merge` 和 `M_PDF_Rotate` 两个 CAD 命令。通过读取 CAD 数据库 `NamedObjectsDictionary` 中的 `Merge_Infor` Xrecord 获取单张 PDF 路径列表，调用 `iTextSharp` 进行合并。 |
| `Mpr2.exe` | .NET 独立控制台程序 (x86) | 作为外部辅助进程运行。读取 `%APPDATA%\MSteel\plot2.tm` 文件（第一行为输出路径，第二行为数量，后续为文件和标题列表），调用 `iTextSharp` 合并 PDF。 |
| `MSteel.prt5` ~ `prt15` | PC3 打印机配置文件 | 包含标准及加长虚拟 PDF 打印机的纸张配置数据。 |
| `SetUp.exe` | 原生安装向导程序 | 向注册表 `SOFTWARE\ZWSOFT\ZWCAD` 的 `Applications` 项写入加载键值。 |

### 1.2 原插件内部通信流程
1. 用户在 CAD 命令行输入 `BP` 或点击菜单，调用 C++ ZRX 模块。
2. C++ 模块弹出 MFC 对话框供用户选择图框、图层或图块。
3. C++ 模块逐张调用 `ZcPlPlotFactory` 打印出单页 PDF 保存到临时目录。
4. 若勾选“合并为一个PDF”，原版采用两种交替机制：
   - 机制 A：在 CAD 数据库的 `NamedObjectsDictionary` 中写入名为 `Merge_Infor` 的 Xrecord，然后调用 `ZCAD2021P.dll` 的 `M_PDF_Merge` 命令。
   - 机制 B：将临时文件清单写入磁盘 `%APPDATA%\MSteel\plot2.tm`，然后通过 `CreateProcess` 唤起外部程序 `Mpr2.exe` 执行合并。

### 1.3 原插件的主要痛点与限制
1. **商业时限与设备绑定**：原版内置时限检测机制（“软件提示过期，只能打印五张”），无法自主可控。
2. **CAD 版本强绑定与 C++ 兼容性碎片化**：原生 C++ ZRX 与特定 CAD 版本的编译器运行时强绑定，跨 CAD 版本（如中望 2021 vs 2025 vs 2026，或 AutoCAD）需要重写重编二进制。
3. **高分屏适配差**：旧版 MFC 界面在 2K/4K 分辨率屏幕下存在字体发虚、表格控件错位的问题。
4. **架构碎片化**：横跨 C++ ZRX、C# DLL、外部 EXE、临时磁盘文件交换，排错维护极为困难。

## 2. 复刻版系统 (`FastBatchPlot`) 架构设计与升级

为了彻底解决上述痛点，我们设计并研发了全新的全托管、跨平台批打印系统：

### 2.1 架构升级点
- **双平台统一抽象桥接 (`FastBatchPlot.CadBridge`)**：
  采用依赖倒置与适配器模式，通过统一接口 `ICadHost` 和 `ICadPlotter`，彻底统一了 AutoCAD（2013-2026）与中望CAD（2020-2026）的核心调用，同一套图框识别与批打印逻辑在两个 CAD 平台上完全通用！
- **完全自主可控，零时限零限制**：
  没有任何注册码、时限、加密或弹窗限制，代码 100% 开放，性能纯净。
- **现代化 DPI 自适应交互界面 (`FastBatchPlot.UI`)**：
  支持 4K 高分辨率自适应，拥有流畅的图纸数据表格，支持实时双击定位高亮图框、多选批量修改图幅与比例、一键导出图纸目录至 Excel。
- **高鲁棒性智能图框识别算法 (`FastBatchPlot.Core`)**：
  - **封闭多段线识别**：正交矩形几何检验算法，自动识别外边框，智能过滤装订内边框与多余嵌套线。
  - **图块识别**：支持常规图块与动态图块（DynamicBlock），自动提取图号、图名、版本、日期、比例等属性。
  - **自适应图幅推断**：内置 ISO A0~A4 及其 1/4、1/2 加长规格库，结合宽高比误差与标准出图比例（1:100、1:50等）自动判定纸张和横竖向。
- **高性能流式 PDF 合并与书签大纲 (`PdfMerger`)**：
  基于高效开源 PDF 流管线，合并单页 PDF 的同时自动生成带图纸序号、图号、图名的左侧多级导航书签。
