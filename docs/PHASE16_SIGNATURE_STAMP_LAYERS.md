# 阶段 16：可配置的签章图层输出控制（2026-09-20）

原版帮助第 8 页明确签名在 MS_Sign 层，第 9 页描述印章由库中透明 PNG 在打印时插入，未明确统一印章层。本项目此前只有 PrintSignatures / PrintStamps 两个字段，关闭任一选项会直接拒绝打印。

## 本阶段实现

- 主窗口新增“签名层输出”“印章层输出”和“签章图层映射”入口。可指定各自的完整图层名；MS_Stamp 只是本程序约定默认值，不能认为原版使用此层。
- 两个开关和映射均进入正式打印/原生预览共同配置入口、任务快照和默认设置。历史 JSON 缺少字段时两个开关默认开启，沿用图层原有状态。
- 关闭时对映射图层临时设置 IsPlottable=false。完整名称忽略大小写匹配，不按片段猜测，不自动匹配外参同名子层。图层不存在时不作修改。开启不强行打开用户原本不可打印、冻结或关闭的层。
- 禁止通配符、空名称、0/Defpoints 通用层、两个类别同层及非法名称。图层上的全部内容均受影响，其他层上的签章仍会输出，窗口中明确说明这一点。
- AutoCAD 2018/ZWCAD 2026 在同一打印事务内临时修改图层；成功后 Abort 回滚，异常时 Dispose 回滚。不提交这些变更，不保存 DWG，不解除锁定或外参限制；设置失败时任务失败。

## 未完成与原生边界

这不是完整签章库。CAD 闭合曲线签名录入、库共享、授权有效期、插入签名、透明 PNG 印章资产、模板印章区域和打印时插入仍待实现。最外边线隐藏仍显式拒绝。

没有启动或连接 CAD，也没有安装包。SDK 编译和离线测试不证明 IsPlottable 在真实预览/驱动中生效；需验收签章隐藏、异常回滚、锁定/外参图层、跨布局、DWG 修改标志和原打印设置恢复。不得宣称已完成原版签名/印章功能。
