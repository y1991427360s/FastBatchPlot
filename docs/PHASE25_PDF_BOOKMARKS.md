# 阶段 25：PDF 书签模板与历史一致性

只处理 PDF 工作流，不涉及图章。

## 问题与修复

原 PlotConfig 和任务历史包含 BookmarkTemplate，但首次合并与历史重合并均写死标题；主窗也没有模板入口。

现在首次与恢复共用 PdfBookmarkItems，从冻结任务设置和图框快照生成标题。主窗“书签…”提供编辑、即时预览及恢复默认；“保存默认设置”持久化模板。旧设置缺字段时补默认，无需升级设置或任务 schema。历史恢复不受当前窗口、时间或 CAD 文档影响。

书签保留中文及冒号、斜杠等标点，比例显示为 1:2.5；文件命名原有清洗规则不变。支持序号 D1—D9、图号、图名、项目、图幅、比例、标题栏日期及版次，中英文占位符均可用。字段内容只替换一次，图名中的花括号和美元符号不重新解释。控制字符转空格，空标题有回退，模板/展开标题最多 32768 字符。

未知字段、不完整花括号、非法精度在提交页面前拒绝。原 DWG 文件名尚未进入历史快照，书签明确不支持该占位符，避免重合并借用当前文档名称。该限制在编辑器说明中展示。
