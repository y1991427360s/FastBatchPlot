# 当前架构

- `Core`：图框、纸张、模板规则、命名、PDF 文件处理；netstandard2.0 / net8.0。
- `CadBridge`：宿主能力接口和来源身份，隔离 CAD API。
- `UI`：WinForms 主窗、模板库、PDF 设置及历史；net48 / net8.0-windows。
- `ZWCAD`：ZWCAD 2026 原生图元采集、交互和打印；当前交付目标。
- `AutoCAD`：保留适配实现与编译，不在当前原生验收范围。
- `Tests`、`UiChecks`、`FrameworkChecks`：分别验证纯核心、假宿主界面与 .NET Framework 行为。

## 字段读取流程

模板库保留导入的字段坐标。ZWCAD 采集图框内部文字、空间 DBText/MText 和并列块的属性/嵌套文字，按当前图框范围过滤。完整块逆变换及右下角锚点把文字转换到模板坐标。

Core 优先按属性标签或文字中心匹配。无中心命中时，只接受唯一与区域有正面积相交的文字；多个候选或中心属于其他字段时不猜测。几何范围由 ZWCAD 适配器提供，此补充路径不能推定其他适配器已具备同样原生覆盖。

读取不写回 DWG。标题栏写回有单独的目标定位和预览检查，不能把读取成功推定为写回验收。

## 模板拾取

UI 按模板库当前选项寻找匹配样本，切换模板清除旧样本。字段拾取时隐藏编辑窗和主窗，CAD 返回两个点后恢复窗口。用户无需预先选择打印列表行；空列表也可使用。样本不存在时可手动指定。

## 输出与验证边界

输出管线包含计划、设备/介质核验、页面提交、文件校验与合并。来源校验行为以阶段 46 和当前实现为准，不能继续沿用阶段 45 的事件计数描述。

当前实机字段证据见 [阶段 47](PHASE47_TITLE_EXTRACTION.md)，其余 PDF 目标及待验项见 [工作范围](PDF_SCOPE.md)。
