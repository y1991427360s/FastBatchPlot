# 第十二阶段：图框模板命名与目录配置联动

日期：2026-09-20。全功能目标继续；本阶段没有启动、连接或操作CAD。

## 已实现

- `TitleBlockTemplate` 增加可选 NamingTemplate / Catalog；旧 schema1 模板缺少字段时兼容，专用设置为空时回退通用值。
- `CatalogOptions` / `CatalogColumn` 使用显式数据契约并校验标题、字段唯一性、列宽、行高；增加深复制，避免模板编辑和默认配置相互污染。
- 模板导入、导出、复制和原子保存覆盖专用目录和命名配置；非法嵌套目录阻止整库替换。
- `TemplateOutputSettings` 集中处理图框块名匹配、命名回退、目录格式候选去重。按块名匹配，不依赖此前提取是否成功。
- 模板编辑器可修改文件命名，编辑/清除专用目录。保存模板后刷新自动文件名；人工文件名始终优先保留。
- 目录窗口可载入原设置，保留列顺序、标题、列名/宽、行高、选择范围和统计选项。发现图框专用配置时，要求用户明确选择本次格式；所选格式应用于本次全部导出图纸，不静默采用第一个模板。
- 每次确认目录设置后保留到当前窗口；点击主界面“保存默认设置”才写入用户偏好，重新打开恢复。取消文件保存对话框也保留已经确认的设置。离线空路径不写用户配置。
- 目录按当前表格显示顺序导出，与本轮前已改进的打印顺序一致。

## 未完成及限制

- 专用目录当前是字段、列名、列宽、行高及标题等配置，不支持任意Excel模板文件中的合并单元格、公式、图片、分页、签署区等版式复用。
- 多模板图纸使用明确选定的一份目录格式，不按模板自动拆成多个目录或工作表；候选包含列表中所有图框模板，最终范围仍由“仅勾选图纸”决定。
- 目录设置保存需点击“保存默认设置”；没有后台自动保存及独立命名的多套通用目录库。模板自身保存会携带专用目录。
- 命名字段采用现有占位符解析，未知占位符保留字面文本；未增加占位符智能补全和严格拼写提示。
- 原版全部功能差距继续包括任意纸张、光栅DPI/背景、共享块文字写回、模板裁切/居中、签章、布局及依赖DWG拆分、真实预览、任务恢复、Excel目录版式模板，以及两宿主原生全流程验收。第九阶段打印原点/旋转与第十一阶段消息循环验收项仍待验证。
