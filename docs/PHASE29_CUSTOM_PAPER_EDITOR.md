# 阶段 29：自定义纸张尺寸编辑

原版 BPHelp 第 3、4 页允许在列表修改纸张尺寸并批量应用；当前项目已有任意尺寸的驱动文件生成，但列表只能修改为内置标准图幅。本轮补齐非标尺寸编辑入口。

在列表选择一行或多行，右键“批量修改图幅 → 自定义尺寸与比例…”：

- 编辑纸张宽、高，单位毫米，支持三位小数。范围 1—100000 mm 是编辑器数值边界，不代表驱动支持范围。
- 默认保持各页原打印比例；内容超出纸张时禁止应用。
- 可明确选择按各页实际打印范围等比适配。模板裁切存在时使用裁切范围，保留宽高比，不拉伸。
- 宽高决定纸面方向；预览展示原比例、留白后的实际尺寸、实际比例。正负/四边留白继续通过统一 PlotPlanBuilder 计算。
- 所有选中行都预检通过才修改列表，每页纸张实例独立；取消和预览不修改原图框或 DWG。
- 更新后刷新自动文件名、方向和纸张统计，保留人工文件名。打印任务运行期间禁止修改。
- 纸张尺寸、方向和非整数比例沿现有冻结任务与历史快照保存，失败重试保持原设置。
