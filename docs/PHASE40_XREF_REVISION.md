# 阶段 40：外部参照来源核验

## 问题

旧来源修订标记仅含主数据库修改事件、会话和路径。外部 DWG 被替换但主图没有编辑事件时，失败页重试可能混用不同版本。此次补强外参证据，不将其宣称为完整出图内容身份。

## 实现

两宿主在 GetSourceRevision 中遍历外参块记录，保存块标识、路径、加载状态，并递归检查已加载外参库。已加载数据库的实际文件名优先于保存的相对路径；嵌套路径相对所属 DWG 解析。磁盘内容使用完整 SHA-256，大小和时间戳相同也能发现替换。缺失和未解析有不同标记，访问失败和并发写入不会被吞成“缺失”。

已加载外参数据库的修改、追加、删除和撤销重做事件纳入会话标记。使用原生数据库指针识别共享/循环引用，保留观察包装器，避免 GetXrefDatabase 重建托管包装器导致无修改也每次换标记；已释放观察对象需要重新建立。嵌套限制 64 层，同一次检查中每个外参文件只读取一次。宿主 API 已通过两套 SDK 编译核对，未运行 CAD。

现有任务入口在初次记录、每页提交前和重试后合并前比较来源标记，因此外参变化可阻止后续页提交及混合合并。只对已生成并验证的完整单页进行独立重合并仍不依赖 CAD。升级前任务的旧标记与新标记不一致时会要求重新建立完整批次。

## 验证与限制

583 项核心测试、354 项离线 UI 检查及 .NET Framework 检查通过。覆盖同大小同时间戳替换、缺失/恢复、独占写入拒绝、嵌套相对路径、替换外参后历史恢复零页面提交。

全内容摘要每次核验都重新读取；大型外参会增加每页预检开销。本次只在单次遍历去重，不按时间戳跨页缓存，避免缓存漏掉同时间戳替换。真实外参加载/卸载/重载、事件噪声及大型图纸耗时仍待原生验收。读取期间文件有共享读锁，但未持有到整页 CAD 输出结束，外部进程并发修改的完整事务一致性仍未保证。

尚未覆盖字体、CTB/STB、PC3/PC5/PMP、图片、PDF 底图等其他外部依赖；跨 CAD 重启自动恢复仍未实现。不能据此声称完整依赖身份或全部功能已经对齐。
