# 第十阶段：标题栏写回、预览与最近一次撤销

日期：2026-09-20。全功能目标仍未完成。本阶段没有连接、启动或操作 CAD，没有修改任何用户 DWG。

## 已实现

- 列表右键“标题栏写回 DWG（预览）”，对已勾选图纸执行。可选图号、图名、工程名称、子项、阶段、专业、版次、日期、比例、设计、校对、审核12字段；使用各图列表值，或将所选字段统一替换为输入值。配合已有图号重编，可预览后写回图号。
- 原有 `ICadTitleTemplateHost` 保持兼容，新增可选 `ICadTitleWriteHost`。`TitleWritePlanner` 在纯核心生成来源、模板、目标身份、旧/新值的独立计划；不存 CAD 对象。
- 采集文字补充实体句柄、所有者、对象类型、原始格式文本和写入阻止原因；支持空属性使用插入点定位，因此空字段也能填写。
- 每个字段必须唯一匹配。区域多个对象、重复标签、多字段/多图框指向同一对象、不同文档、无模板规则、非法控制字符、过长值、CAD字段/文字控制码均阻止整批执行。
- 可写目标为来源图框实例属性（含多行属性）及同空间的独立 Text/MText。共享块定义文字、嵌套块属性、常量属性、CAD字段表达式、锁定图层及锁定图框图层明确阻止写入，避免误改其他图纸。
- 写入前重新执行模板匹配，比较实体身份、原值、位置、类型及可写性；在同一来源文档锁与数据库事务中先检查全部目标，再写入并读回原始值，全部成功才提交。期间任何异常使事务回滚。
- 多行新文字按纯文本转义反斜线、花括号和换行。修改后的行内格式会替换；未变更的显示文本不重写，保留原格式。Text 调整对齐；这些 API 的真实显示效果待宿主验收。
- 成功后才更新列表元数据和状态。提供最近一次 DWG 写回撤销，检查当前原始文本仍等于上次写入值；手工改动或目标锁定后拒绝整批撤销。撤销不自动重写列表，界面提示重新提取。
- 不自动保存 DWG，不自动执行 CAD 命令，不关闭文档；程序窗口关闭后丢弃内存撤销计划。

1. 没有原生写回验收。事务回滚、字段检测、对齐、多行属性更新、动态块与真实文字显示只能在两宿主真实图纸验证后确认；纯核心测试不覆盖CAD数据库事务行为。

3. 空间区域定位依赖文字包围盒中心，写入较长文字后可能离开原区域；属性标签定位更稳定。后续重新提取可能出现多对象/无对象提示。
4. 撤销只恢复原始文字内容，不恢复后续人工几何/样式编辑；当前值不等于上次写入值时拒绝撤销。未创建独立CAD原生撤销组或持久化修改日志。
5. 无自动字号压缩、溢出排版、按字段分别输入不同统一值；可分次更新版次、日期等。手工文本格式、组合文字、分段多对象写回未实现。
