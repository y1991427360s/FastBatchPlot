## 本轮改动

- 输出类型从固定 PDF 改为 PDF、DWF、PLT、PNG、JPG、EPS、SVG、实体打印机。扩展名来自选定格式，仍使用唯一临时文件，校验通过后以不覆盖方式提交。
- 两宿主移除靠驱动名含 PDF 的硬编码判断，改读 `PlotInfo.ValidatedConfig.PlotToFileCapability`：仅文件驱动拒绝设备提交，不支持文件的设备拒绝文件输出。选择格式不会自动安装或切换驱动，也不会转换驱动内容；用户须选择对应设备。
- 新增 `ICadPrinter` 独立提交接口，共享已实现的来源、布局恢复、精确比例和介质匹配流程。份数 1—999，通过 CAD `BeginDocument` 传递；文件输出固定 1 份。
- 实体打印不创建输出目录、不要求生成文件、不合并 PDF。成功状态为“已提交设备”，明确不等于纸张实际输出。
- 设备任务某页失败时停止后续页并标记未提交；不自动重试。若提交已经开始但后续失败，错误信息提示该页可能已被设备接收，需先检查队列。
- 所有页面在提交前先验证数值打印计划；介质/驱动校验仍逐页进行，尚无完整设备批次预检。
- 切换模式同步启用适用控件，打印期间禁用，结束后按当前模式恢复。非 PDF 无合并，实体打印启用份数并禁用文件目录/命名。
- 默认设置新增格式、设备输出模式和份数，保持版本 1 的可选字段兼容；旧设置缺少这些字段时为 PDF、文件输出、1 份。

## 文件校验强度与边界

| 格式 | 已实现校验 | 尚未证明 |
|---|---|---|
| PDF | 可读、单页、毫米尺寸与计划一致 | 工程内容无遗漏、驱动线宽颜色完全正确 |
| PNG/JPG | 实际编码匹配、宽高比、完整解码、单帧；150MP 上限 | DPI、物理尺寸、背景色和目标分辨率 |
| DWF | DWF 前导、DWF6 ZIP 目录、XML 清单、资源可读及长度；解压总量512MB上限 | 真正 W2D/W3D 内容、页数、比例；旧版非ZIP DWF不支持 |
| SVG | 禁止 DTD/外部实体，完整 XML、SVG 根节点、有图形元素 | 渲染完整性、外部图片/字体依赖、毫米尺寸 |
| EPS | Adobe EPS 文件头及数值 BoundingBox | 全文件 PostScript 语义、绘图内容与真实尺寸 |
| PLT | 前1MB中识别 HP-GL/2 初始化与绘图指令 | 全流语义、截断检测、PCL等其他PLT方言 |

这些检查不等同于所有格式的完整成果验收。DWF 测试使用合成容器，只验证容器检查路径；EPS/PLT/SVG 测试使用最小结构，不是 CAD 实际导出。当前只有 PDF 继续核验物理毫米尺寸。光栅驱动若采用像素介质而不是毫米介质，现有介质匹配可能明确失败，未做专属分辨率换算。
