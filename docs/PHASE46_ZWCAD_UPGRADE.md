# 阶段 46：中望版全面检查与升级（2026-09-24/25）

用户要求：只做中望 CAD 批打印（暂不适配 AutoCAD），全面检查、全面升级，对标 `M-批打印软件(中望版)V20260805B`。

本阶段先由三路只读审查（核心识别/纸张、PDF 输出流水线、中望适配层 API）找出问题，再逐项修复并补测试。**未连接或操作用户正在使用的中望 CAD**（当时打开着实际工程图），原生验收见文末清单。

## 1. 影响日常出图的严重问题（已修复）

| 问题 | 后果 | 修复 |
| --- | --- | --- |
| 来源修订标记累加 `ObjectModified/ObjectOpenedForModify/Appended` 等全部数据库事件，并在每页前后各算一次全空间指纹 | 中望切换布局、恢复视图、打印时的内部事件让正常页面被判“原图已变化”而失败，后续页全部失败；每页 3 次全空间哈希，大图 O(n²) | 去掉事件计数，只用实体内容指纹（新增图块位置/缩放/属性）和外参文件摘要；新批次不再逐页复核（仅历史重试混用旧页时复核）；合并前复核改为提示而非拒绝；指纹流式计算不再整块复制内存 |
| 重新出图到同一目录直接报“输出已存在”，没有覆盖选项 | 与原版习惯不符，第二次出图必失败 | 新增“覆盖同名文件”（默认开，存入默认设置与任务历史）；先写临时文件并校验再 `File.Replace`；出图前预检同名文件是否被 PDF 阅读器占用或只读 |
| `.tk` 解析把第 1 行（块名）当模板名、第 2 行（ABCDEFT 命名规则）当块名；旋转/插入比例按整数解析；固定 58 行记录 | 图框型模式按 `A-C` 等命名规则去匹配块名，**实际图框一个也识别不到**；命名规则丢失；带字体设置的 82 行记录及其后的节被截断，往返导出损坏文件 | 按原版格式重写解析/导出：块名、命名规则（转换为 `{图号}-{图名}` 等并可反向写回）、弧度与插入比例（字段区域按旋转/比例换算回块内坐标）、按 `<><` 分段支持变长记录，两个真实样本（27/236 个图框）逐行无损往返 |
| 纸张识别在 A 系列 2 倍关系时优先“最接近 1:100” | 布局 1:1 的 A1 识别成 1:2 的 A3、A1 1:50 识别成 A3 1:100、A3 1:150 识别成 A1 1:75 等 | 以几何误差为主（区分 841 与 840 的 0.1% 差异），仅几何完全等价时按对数距离偏好常用比例 |
| 自动纸张接受 8% 误差 | 伸出外框的会签栏被识别成标准纸，出图时才因放不下失败；表格、设备外框被误认作图纸 | 误差阈值统一为 3%、长宽比 5%；范围超出标准纸 1.5mm 以上时按“范围 ÷ 比例”生成非标纸（与原版说明一致） |
| 加长图幅表只到 +1、缺 1/8 级 | A1+5/4、A2+2、A3+3/2 等常用加长图纸被丢弃 | 按 GB/T 50001 及原版 `.tk` 加长列表重建（A0 至 +1、A1 至 +3/2、A2 至 +5/2、A3 至 +7/2，含 1/8 级） |
| 镜像图块缩放为负，比例提示被忽略 | 镜像 A1 图框识别为 1:2 的 A3 | 比较缩放绝对值 |
| 按图号 / 模板优先级排序只在单个布局内进行 | 多布局、多文件批次的目录页无法排到最前 | 这两种排序改为全局排序（图号相同时保持图面顺序） |

## 2. 用户环境安全

- 删除 `EnsureZeroMarginPmp`：此前每次打开窗口都会静默改写 `Plotters\PMP Files\M_PDF.pmp`（原版插件的配置）的页边距。现在不修改任何用户或其他插件的 PC5/PMP。本机该文件已有 `.orig` 备份，但当前内容也经其他程序改写过，未自动还原，由用户自行决定。
- 驱动不接受临时目录绝对路径时暂存到打印机目录的 `FBP_*.pc5/.pmp`：暂存副本的 PMP 引用改为指向同目录副本，并随打印结束删除；打开窗口时清理一小时前异常遗留的 `FBP_` + 32 位十六进制文件。
- 打印错误日志从桌面 `FastBatchPlot.log` 改到 `%LOCALAPPDATA%\FastBatchPlot\logs\plot-errors.log`，超过 2MB 轮转；“更多 ▾”可打开日志目录。
- 外参摘要以共享读写方式打开，同事正在编辑网络外参时不再导致整批失败。

## 3. 中望适配层

- 布局保存时激活了浮动视口：打印时自动切回图纸空间，结束后恢复原状态（原先整页失败）。
- 从对话框拾取：模态窗口通过 `Editor.StartUserInteraction` 交还 CAD 主窗口，非模态窗口先把焦点交给图形窗口；模板字段区域拾取不再在持有文档锁和事务期间等待用户输入，拾取后核对图框未变化。
- 框选、图集范围、模板锚点：单个无法取范围的实体（空块、未加载外参、代理对象等）只跳过自身并提示数量；图集中含构造线/射线时明确报错。
- 图框标记（红框/序号）与高亮：只画在图框所属文档的当前空间；切换或关闭文档时正确清除，不再在其他文档擦除失败并释放仍显示的瞬态对象。
- “定位此图”按当前视图方向/扭转换算到显示坐标；在布局浮动视口中不再执行缩放（避免改动视口比例）。
- 已打开主窗口时再次输入 `BP`/`BP_TY`/`BP_TK` 只激活窗口（原先抛异常）。
- `BP_TRUE2INDEX`：只读打开后按需升级，锁定图层跳过并计数（原先遇到锁定图层整体失败）；同时转换图层与普通块定义中的真彩色。
- `BP_INSERT_TK`：尊重 UCS、Esc 取消不再插入默认图框，加长图幅关键字改为 `A3L`/`A2L`（关键字不能含 `+`）。
- 模板图框：已登记纸张尺寸时直接按“范围 ÷ 登记纸张”确定比例；单个模板图框解析失败记入识别报告并跳过，不再中断整次搜索。
- 手工/模板句柄使用 `TryGetObjectId`，陈旧句柄给出中文提示。

## 4. 界面与性能

- 工具栏重排：最小窗口下三行完整显示（原先第 4 行被裁切需滚动）；输出类型/份数移到“打印设备”一行；“保存为默认设置”“PDF 任务历史”“打开错误日志目录”收进“更多 ▾”。
- 新增：右键“纸张统计”（含折合 A1，可复制）、“打开输出目录”“打开选中行的输出文件”；输出目录旁“打开”按钮；“完成后打开”（定位合并 PDF 或打开目录，默认开并随默认设置保存）。
- 批量输出时标题栏显示进度 n/N，状态列按成功/失败着色并自动滚动到当前页；每页只刷新状态单元格，不再整表重建（大批次闪烁、跳回顶部）。
- 设备纸张列表按设备缓存（原先每页枚举并切换全部纸张）；任务历史保存时若文件未被其他进程改写则跳过整份重新解析（原先每页两次全量解析，O(n²)）。
- 文件名：`{纸张尺寸}` 输出实际尺寸（如 `841x594`），新增 `{信息1}`/`{信息2}`/`{子项}`；超长文件名截断到 120 字符；`CON`/`PRN` 等保留名自动追加下划线而不是整批失败。
- 旧版本错误导入的模板库（大量块名为 `A-C`/`A-MLE`）会在主窗口提示重新导入。

## 5. 发布与安装

- `Build-Release.ps1` 默认只打包中望版（`-IncludeAutoCAD` 可同时打包 AutoCAD 2018）；`Install-All.ps1` 只安装包内存在的目标，提示文字改为中望。
- `一键安装.bat`/`一键卸载.bat` 原为 GBK 编码却执行 `chcp 65001`，中文标题和提示乱码；改为 GBK + CRLF 且不切换代码页。`Install-All.ps1` 补 UTF-8 BOM（Windows PowerShell 5.1 读取无 BOM 脚本会按 ANSI 解析中文）。
- 测试不再依赖个人桌面文件：两份真实 `.tk` 样本放入 `src/FastBatchPlot.Tests/Fixtures`。
