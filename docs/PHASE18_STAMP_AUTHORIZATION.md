# 阶段 18：印章授权码、有效期与旧框架图片依赖修复

日期：2026-09-20。依据原版帮助第 8—9 页的授权码、有效期及共享库语义，继续完善阶段 17 的印章资产。本阶段没有复制原版商业注册机制或专有库格式。

## 使用流程

1. 在印章库选中 PNG，点击“授权设置”。可设置 8—128 字符授权码及最后可用日期。所选本地日期全天可用，截止为次日零点，不包含该时刻；界面显示完整时区和实际截止时间。
2. 受保护资产默认不显示图片，也不能直接改名。预览、改名、改码、续期、移除保护或在界面删除时需要原授权码。过期资产可管理和续期，不能直接出图。
3. 授权编辑仅生成内存草稿，取消不写库；在库窗口确认才保存。无修改的选择不重写文件，保留只读共享库用法。
4. 打印/预览受保护资产时输入授权码。解锁凭据仅在当前主窗内存中复用，不写用户设置或共享库。关闭印章输出会清除凭据，并跳过库读取。
5. 每页在准备及进入打印引擎前重读共享库，检查所选资产是否仍存在、图片或授权是否改变以及是否到期。无保护资产也检查，防止批次中途加保护/删除后继续输出旧版本。发生变化时拒绝该页，不悄悄换图，也不提交未经授权的页。

原来的无保护 PNG 库仍能使用。给资产添加保护时保存为版本 2；旧版本 1 仍可读取，但旧程序不应读取版本 2。移除保护会移除本阶段的授权期限并恢复普通 PNG，界面有明确提示。

## 实现与边界

- `StampAuthorization` 独立于 CAD 和界面。使用系统密码库 PBKDF2-HMAC-SHA256（210000 次、随机 32 字节盐）派生两个独立 256 位密钥，AES-CBC/PKCS7 加密、HMAC-SHA256 先认证后解密；每次保护使用随机 IV。
- 认证覆盖域标记、资产 ID、名称、尺寸、算法版本、迭代数、到期 UTC 时间、盐、IV 和密文。保护资产的 `PngBase64` 强制为空；删除保护字段不能把密文降级成可用明文。拒绝非法 UTF-16，避免 UTF-8 替换字符导致不同名称/授权码映射相同字节。
- `StampUsePermit` 只持有私有内容副本和指纹，不保留授权码或派生密钥；返回资产仍是副本。出图同时检查本机 UTC 和从解锁开始的单调经过时间，明显回拨时拒绝继续使用。任务快照深复制保护信息，凭据本身不可变。
- `StampOutputGuard` 把逐页共享库和授权检查集中到核心服务，两宿主复用。库不可读、删除、内容变更、授权变更、期限到达均不允许继续提交相关页。已经进入设备的页无法撤回；界面继续保留“检查打印队列，避免重复提交”的提示。
- **这是本机离线内容保护，不是可信时间或数字签章系统。** 用户持有同一授权码即可使用和管理。不能防止有写权限者删除整个库、恢复旧版本库、绕开程序使用已经取得的明文、修改程序/系统时间；不保证历史缓存和用户备份中原来的无保护 PNG 消失。打印期间 CAD 需要临时明文 PNG，结束尝试删除，不承诺抵御同账户进程或磁盘取证。共享撤销按逐页检查时刻生效，不提供跨网络的瞬时撤销。

## 发现并修复的兼容性问题

独立 Windows .NET Framework 验证暴露此前仅构造主窗未覆盖的问题：ImageSharp / System.Memory / System.Threading.Tasks.Extensions 引用 `System.Runtime.CompilerServices.Unsafe 4.0.4.1`，随包为 `4.0.6.0`，没有宿主绑定重定向时 PNG 导入会失败。独立 net48 EXE 和 Windows PowerShell 都复现，不能归因于 CAD。

`LegacyDependencyResolution` 仅为同目录已知依赖，或当前线程同步图片操作作用域内无请求者信息的泛型 JIT 加载，映射已确认的强名版本 4.0.4.1 → 随包 4.0.6.0。不更改 CAD 的 EXE.config；不为任意程序集/任意版本重定向。PNG 导入、校验以及 PNG/JPG 输出校验均进入作用域，私有图片方法禁止内联，保证 JIT 解析发生在作用域内部。

这是限定范围的 AppDomain 依赖兼容处理，**不等于与其他 CAD 插件完全隔离**。与宿主其他插件的组合仍待原生验收。后续若升级这些依赖，应重新审核精确身份和兼容映射。
