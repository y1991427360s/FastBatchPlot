# 第一阶段：正确性基础整改

日期：2026-09-20。完整复刻目标仍在进行，本文件只记录第一阶段实际完成的源码与离线验证，不表示原版所有功能已实现。

## 已整改

- 表格操作绑定图框对象，修复表头排序后改错/选错/删错；单图重新排序不再消失。
- 标准纸张返回独立对象，图幅选择更新完整尺寸；手工文件名不再被刷新覆盖。
- 块插入缩放提示不合适时重新推断；无效外围矩形不再先吞掉有效图框；混合块/多段线联合处理，指定块不存在严格返回空，不再强制10%面积过滤。
- 全边矩形校验拒绝自交；轻量多段线不再把带圆弧段或非标准实体平面的端点当普通矩形。
- ACI 使用带固定来源与 MIT 许可的参考查表，替代错误 HSL 计算；属性中的 `$` 按字面替换；小数比例在目录/名称中保留。
- 添加独立于 CAD 的 `PlotPlanBuilder`：精确比例、正留白扩大纸张、负留白保持纸张并缩小内容；超出纸张报错，不静默布满。
- 从打印驱动读取实际纸张及可打印区域，拒绝缺纸和裁切；样式失败传播；引擎忙碌明确失败。
- 每个图框携带源文档会话与空间标识；打印/定位前校验，不能把旧列表用于新图。
- `PlotOutputCommitter` 使用独立临时文件，检查 PDF 单页和物理尺寸再提交，不用旧产物冒充成功。
- UI 输出前检查非法路径、重名、系统保留名称及已存在文件，拒绝静默覆盖；失败统计与成功页合并分开说明。
- 打印时锁定任务交互与关闭，移除 DoEvents 重入，异常后 finally 恢复；目前是同步串行流程，尚未实现取消与后台进度。
- PDF 合并与旋转先写唯一临时文件，再原子替换；合并拒绝输入输出同路径，非法角度明确失败；截断旧任务清单不再少合并却成功。
- 修复底部开始按钮越界和窄窗口工具条裁剪，增加独立 `FastBatchPlot.UiChecks` 回归执行器。

## 当前限制

1. 仅 PDF 输出分支可靠性整改；其他格式、实体打印机、DWG 拆分、模板录入与字段写回、签章库尚未实现。
2. 正留白需要驱动已有精确扩大纸张；缺规格会明确报错，尚不能自动创建任意纸张。
3. 只接受未旋转的二维俯视；透视/倾斜/旋转视图及布局中激活浮动视口明确拒绝，待原生验证后扩展。
4. 签名/印章/外边线隐藏尚未实现；传入这些隐藏选项会明确拒绝，不能视为已有签章能力。
5. PDF 设备目前通过名称含 PDF 进行初筛，最终通过真实 PDF 文件校验；设备能力描述仍需进一步抽象。
6. 识别仍受标准图幅库、比例歧义和包围盒近似限制；不是任意图纸自动识别保证。
7. 部分应用编排仍留在 WinForms；本轮提取了打印计算、介质匹配与产物提交服务，完整应用层、不可变任务快照、取消/历史/恢复继续按审查路线推进。
8. 旧安装脚本仍使用 Debug 路径，旧 Bundle 不会自动更新；本轮不要据这些旧入口判断新的 Release 已部署。

源码备份目录记录在 `audit-evidence/baseline-backup.txt`。原审查报告的缺陷表是整改前快照；本文件说明已处理范围，待原生验证项目仍不得标为验收通过。

下一阶段应落实可搬移发布包与任务服务，再补原版通用工作流；模板型工作流和签章模块随后按功能矩阵逐项验收。
