# 阶段 39：纸张尺寸列与实际 PDF 计划

## 原版依据和问题

原版帮助第 3—4 页说明可在列表编辑纸张尺寸/比例，并通过表头统一修改全部图纸。此前项目已有右键自定义纸张窗口，但列表仅显示标准名，没有尺寸、留白后尺寸或实际比例；比例显示仅两位小数。

## 修改

新增“基础尺寸 mm”“PDF 尺寸 mm”“PDF 实际比例”三列。基础尺寸支持宽 × 高、x/X、* 分隔，限定 1—100000mm 和三位小数，不接受歧义千位分隔或科学计数。直接修改保持原比例，先用统一 PlotPlanBuilder 校验，尺寸无法容纳内容时恢复原值并说明原因；可双击打开既有适配窗口。

PDF 尺寸与实际比例只读，跟随正负留白、四边留白、纸张、比例、模板范围和列表刷新更新。无效计划显示“设置无效”及对应错误提示。它们是计划值，不代表驱动已接受或 PDF 已验证。直接比例编辑保留现有行为，数值有效但放不下时即时显示计划错误，打印前仍严格拒绝。比例显示扩展至八位小数，模型数值不截断。

点击基础尺寸表头打开全部图纸尺寸预览，点击比例表头打开全部图纸统一比例预览（包括未勾选行，窗口明确标注）。全批预检成功才一次应用，取消不修改。双击编辑单元格不再误触 CAD 定位；只读列保留定位入口。新增列使用名称访问，保留历史编辑列索引和行对象绑定。
