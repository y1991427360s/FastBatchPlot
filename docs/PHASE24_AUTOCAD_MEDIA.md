# 阶段 24：AutoCAD PDF 独立纸张配置

本阶段继续 PDF 专项，图章不在范围。已给 AutoCAD 2018 接入缺少精确纸张时的独立 PC3/PMP 生成路径，仍未进行原生 CAD 验收。

## 实现

- PiaConfiguration 独立读写 PIA 文本与压缩容器：固定头、压缩长度、解压长度、压缩体 Adler32、zlib 内部内容校验；解压最大 4 MiB，限制行数和嵌套深度，拒绝重复字段/节点、结构未闭合、非法控制字符。中文使用严格 GBK；字符串开头引号至行尾，不误加闭合引号。原数值的附加精度表示保留。
- AcadPdfMediaFiles 读取所选原生 PDF PC3，为最终计划宽高生成唯一文件名、唯一介质标识及单张纸 PMP。更新 PC3 选纸、可打印区域和 PMP 关联；PMP 的 size 与 description 通过名称关联，描述毫米宽高、零边距和面积。保留源驱动身份及其他原始设置，不复制原版 M 软件资源作为运行/发布依赖。
- 只接受已识别的 AutoCAD PDF 配置，不用于系统打印机或其他驱动。已关联其他 PMP 的配置明确拒绝，以免丢失原校准或驱动覆盖设置。PMP 不虚构能力位、不提升驱动最大纸张能力；是否接受生成介质以驱动回读为准。
- 文件放工具私有临时目录，持读锁直到引擎、PlotInfo、PlotSettings 全部释放；只清理自己创建的文件。既有设备配置、PMP、搜索路径不修改。清理失败保留成功 PDF 并提示残留目录。
- AutoCAD 适配器通过设备列表定位唯一 PC3，缺纸张且介质枚举完整时才尝试生成。验证后的完整路径、纸张标识、实际尺寸/区域、单位、比例、窗口、原点、样式必须与独立请求一致；不接受近似介质或驱动替换。PDF 最后仍验证实际页尺寸。

## 证据与限制

静态格式依据包括本机官方 DWG To PDF.pc3、官方 PublishToWeb PNG.pmp 的通用 PIA 结构以及已有 PDF PMP 的字段结构对照。仅只读检查，没有操作或调用 CAD。生成文件不包含原版纸张表、资源名称或专有二进制。

**生成文件的格式与尺寸检查通过，不证明 AutoCAD 接受该 PMP。** 独立路径解析、PMP 省略能力元数据是否可被原生驱动接受、现有官方 PC3 中历史驱动路径的解析行为、介质方向/纸张组语义等，均须原生验证。代码失败时明确停止该页，不自动改用户配置来掩盖失败。当前不能称为已经可交付的任意尺寸打印能力。

未支持已有自定义 PMP 的无损迁移；未补齐分辨率、文字转轮廓、外边线等功能。两宿主介质适配仍有重复，应在原生行为稳定后继续提取共享验证值对象，不能仅为减少代码量抹平 SDK 差异。
