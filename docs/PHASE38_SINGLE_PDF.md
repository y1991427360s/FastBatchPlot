# 阶段 38：单张 PDF 快速输出

## 原版依据与缺口

原版帮助第 2 页：两点确定范围或选择打印图形，默认写临时文件并打开，确认后另存；也可选择保存位置。此前项目只能添加范围后进入批量流程，没有这一独立入口。

## 实现

主窗和右键菜单增加“单张 PDF…”。支持列表中高亮选中的一行、两点范围、图形集合三种来源。手工范围通过既有宿主接口询问比例；选中行使用该行纸张和比例。设备、样式、留白、外边线控制和 PDF 专用参数沿用主窗，任务副本强制单份 PDF、不合并。原批量列表、勾选状态、人工文件名和批量合并设置保持不变。

默认输出至系统临时目录 FastBatchPlot/SinglePdf 下独立随机目录，生成后请求默认查看器打开。结果窗口提供再次打开、另存为；右键菜单可再次打开本会话最近单张成果。未主动清理用户成果，界面提示临时文件可能被系统清理。

选择保存位置时，新文件沿用拒绝并发覆盖规则。已存在目标须经过保存对话框明确覆盖确认，然后先输出独立临时成果，完整复制并校验后以原子替换提交；失败时保留临时成果并显示路径。另存不重新调用 CAD，保持 PDF 原始字节。

复用统一任务调度、来源检查、任务历史和错误恢复。单张在成功记录前校验页数、PDF 结构和计划纸张尺寸；取消手工选择不创建输出，失败恢复主窗。打开查看器失败不会把已生成成果误报成打印失败。

## 边界

提供独立范围选择项，不复刻原版命令行 Tab 切换和 S 快捷键。默认查看器能否正常启动以及 CAD 范围选择、驱动真实出图尚未原生验证。覆盖另存后历史仍记录最初输出路径；历史不声称追踪用户后续保存副本。
