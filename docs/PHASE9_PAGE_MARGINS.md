# 第九阶段：四边独立留白与纸面位置规划

日期：2026-09-20。全功能目标仍未完成。本阶段无 CAD 启动、连接或操作，发布包仍待原生验收。

## 改动

- 新增 `PageMargins` 和 `MarginMode`，统一留白兼容原有正负毫米设置；四边独立模式使用 0—100mm 非负数，明确选择“增大纸张”或“固定纸张缩小内容”，避免正负混用歧义。
- 增大纸张：左右/上下边值分别加入纸宽/高，比例不变。固定纸张：按可用区占纸张的最小宽高比等比缩小，内容在扣除留白后的区域居中。
- 留白按最终横/纵纸面解释；若内容与纸张比例不完全相同，额外空隙均分，四边值为保留区域要求，不保证每一边恰好等于输入值。
- `PlotPlan` 保存内容左/下位置，既有固定比例超范围错误继续阻止输出，不能静默 fit。
- `PlotMedia` 新增驱动可打印区左/下位置，两宿主读取实际 `PlotPaperMargins`。介质选择同时检查尺寸及内容矩形位置，修复仅凭宽高判断会漏检偏移硬边距的问题。
- 两宿主关闭自动居中，使用计划的内容位置减去可打印区域原点后设置 `SetPlotOrigin`。90°模式按介质到最终纸面 `(x,y) -> (y,W-x)` 转换硬边距。这是待原生核验的坐标约定，不能将纯数学测试当作驱动证据。
- 主窗口留白输入旁提供“四边…”按钮；独立模式禁用统一数值。弹窗逐图显示目标纸张、实际比例、实际四边空白和错误，错误时禁止应用。该窗口是几何计划预览，不是图纸内容或驱动真实预览。
- 默认设置增加可选 margins 字段并深复制保存；旧 schema1 文件缺字段时恢复统一模式。模式和四边值非法时拒绝保存，保留原文件。
- 任务期间禁止修改留白；任务结束恢复当前模式的控件状态。

- 原版手册明确描述统一正负留白；四边独立留白属于增强能力，不等同于已经补完原版其他差距。
